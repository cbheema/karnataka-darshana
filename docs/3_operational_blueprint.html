Section 4

Content Writer Quality Criteria Checklist

Enforce these 5 rules before approving any writer submission.

1 Length Budget (60–90 Words)

Descriptions must not exceed 90 words. A ~75 word passage takes ~35 seconds to synthesize at 1.0x speed, preventing listener fatigue while keeping UI transcription cards compact.

2 Spoken Punctuation for Speech Synthesis

TTS voices require punctuation to take breaths. Use commas (,) for 250ms cadence breaks and periods (.) for 500ms stops. Never submit a 30-word run-on sentence without a comma.

3 Kannada Unicode & Full-Stop Rule

ಕನ್ನಡ ವಿವರಣೆಗಳಲ್ಲಿ ಎಂದಿಗೂ ಡಬಲ್ ದಂಡ (॥) ಬಳಸಬೇಡಿ. ಯಾವಾಗಲೂ ಪ್ರಮಾಣಿತ ಪೂರ್ಣವಿರಾಮವನ್ನು (.) ಬಳಸಿ. ಇದರಿಂದ ವೆಬ್ ಸ್ಪೀಚ್ ಸಿಂಕ್ ಸರಿಯಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ.

4 Expand All Numerals & Eras

Never write "12th c." or "500 m". Write "twelfth century" and "five hundred meters". This ensures the speech engine speaks fluent words instead of reciting isolated letters.

Section 5

CLI Automation Script (Python)

Save this script to your project folder to automatically merge submitted CSV files into items.json.

# save as ingest_content.py
import csv
import json
import os

CSV_FILE = 'content_submissions.csv'
JSON_FILE = 'items.json'

def build_items():
    if not os.path.exists(CSV_FILE):
        print(f"Error: {CSV_FILE} not found.")
        return

    items = []
    with open(CSV_FILE, mode='r', encoding='utf-8') as f:
        reader = csv.DictReader(f)
        for row in reader:
            if not row.get('id'):
                continue
            item = {
                "id": row['id'].strip(),
                "category": row['category_en'].strip(),
                "category_kn": row['category_kn'].strip(),
                "title": row['title_en'].strip(),
                "title_kn": row['title_kn'].strip(),
                "year": row['year_en'].strip(),
                "year_kn": row['year_kn'].strip(),
                "location": row['location_en'].strip(),
                "location_kn": row['location_kn'].strip(),
                "imageUrl": row['image_url'].strip(),
                "imageAlt": row['image_alt_en'].strip(),
                "description": row['description_en'].strip(),
                "description_kn": row['description_kn'].strip(),
                "flipCards": [
                    {
                        "q": row['card1_q_en'].strip(),
                        "q_kn": row['card1_q_kn'].strip(),
                        "a": row['card1_a_en'].strip(),
                        "a_kn": row['card1_a_kn'].strip()
                    },
                    {
                        "q": row['card2_q_en'].strip(),
                        "q_kn": row['card2_q_kn'].strip(),
                        "a": row['card2_a_en'].strip(),
                        "a_kn": row['card2_a_kn'].strip()
                    }
                ]
            }
            items.append(item)

    with open(JSON_FILE, mode='w', encoding='utf-8') as f:
        json.dump(items, f, ensure_ascii=False, indent=2)

    print(f"✅ Successfully compiled {len(items)} items into {JSON_FILE}!")

if __name__ == '__main__':
    build_items()
