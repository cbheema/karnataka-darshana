SECTION 01 Foundations

System Overview & Philosophy

The OmniView Bilingual Knowledge Hub implements a Zero-Build Fat-Client Single-Page Application pattern. The application is completely self-contained within a single HTML5 file, consuming external bilingual JSON datasets without requiring build-step bundlers (Webpack, Vite, Rollup) or transpilations.

Zero Runtime Overhead

No virtual DOM diffing libraries. State transitions compile to direct DOM mutation cycles, keeping runtime memory footprints under 15MB.

Parallel Bilingual Schema

Native Kannada (ಕನ್ನಡ) script and English parity across all models: narrative text, metadata, speech synthesis, and trivia cards.

CORS-Resilient Tri-Tier Pipeline

Functions reliably over http://, direct disk execution via file:///, or offline sandboxes via automated fallback cascades.

SECTION 02 Topology

Architectural Blueprint & Component Flow

The system enforces unidirectional reactive state dispatching. Changes to the current locale ('en' | 'kn') or active image entry trigger synchronized re-renders across the visual viewport, speech engine utterance parameters, and trivia decks.

SECTION 03 Data Contract

Bilingual Data Schema & Types

The data layer requires symmetric dual-language properties. By adhering to key pairs ending in _kn, developers can add arbitrary content without creating isolated files for different languages.

schema.d.ts 
export interface TriviaCard {
  q: string;             // English Question
  q_kn: string;          // Kannada Question (ಕನ್ನಡ ಪ್ರಶ್ನೆ)
  a: string;             // English Answer Insight
  a_kn: string;          // Kannada Answer (ಕನ್ನಡ ವಿವರಣೆ)
  icon?: string;         // Optional FontAwesome icon (e.g. 'fa-landmark')
}

export interface OmniViewItem {
  id: string;            // Unique URL-safe slug ('hampi-stone-chariot')
  title: string;         // Headline in English
  title_kn: string;      // Headline in Kannada (ಶೀರ್ಷಿಕೆ)
  category: string;      // Category filter key (e.g., 'Architecture')
  category_kn: string;   // Kannada category pill
  year: string;          // Epoch or timestamp ('16th Century CE')
  year_kn: string;       // Kannada Epoch ('೧೬ನೇ ಶತಮಾನ')
  location: string;      // Geographic entity
  location_kn: string;  // Kannada Location
  image: string;         // Absolute URL or relative asset path
  description: string;   // English speech script & karaoke text
  description_kn: string;// Kannada speech script & karaoke text
  triviaCards: TriviaCard[];
}

The Polymorphic Accessor Pattern

To prevent repetitive conditional branching, a dedicated helper function safely resolves localized values with automatic fallback:

function getLocProp(item, field) {
  return (currentLocale === 'kn' && item[field + '_kn']) ? item[field + '_kn'] : (item[field] || '');
}
SECTION 04 Security & Transport

CORS & Resilient Ingestion Pipeline

Standard browser security restricts asynchronous fetch() queries when a web page is executed directly off the local disk using the file:/// protocol. To make the architecture zero-setup for both production web servers and local learners, the ingestion pipeline implements a three-tier fallback hierarchy.

TIER 1 Default

Async HTTP Fetch

Attempts fetch('items.json') on standard Web servers (Vercel, Apache, Python HTTP server).

TIER 2 file:/// Safe

HTML5 FileReader

If CORS blocks the fetch, triggers a file picker that streams disk data into memory via reader.readAsText().

TIER 3 Fail-Safe

Embedded Backup Array

If no local file is selected, automatically loads an in-memory bilingual dataset so the UI remains interactive.

SECTION 05 Audio Engineering

Web Speech Synthesis & Karaoke Tokenizer

The audio narration features synchronized word-by-word transcription tracking using the browser's native SpeechSynthesisUtterance engine. This avoids third-party cloud audio dependencies and reduces bandwidth consumption to zero.

The onboundary Event Mapping Algorithm

When speech synthesis runs, the browser fires an onboundary event emitting an absolute character offset (event.charIndex). The tokenization engine builds an indexed lookup table mapping character ranges [start, end] to target DOM span elements:

utterance.onboundary = (e) => {
  if (e.name === 'word') {
    const targetSpan = wordTokenMap.find(t => e.charIndex >= t.start && e.charIndex < t.end);
    if (targetSpan) highlightAndScroll(targetSpan.element);
  }
};
SECTION 06 Computer Graphics

3D CSS Mathematics & Flip Card Engine

The flashcards use hardware-accelerated 3D coordinate transformations. By nesting three hierarchical coordinate planes, cards achieve authentic physical perspective, light refraction, and backface culling.

1. Perspective Projection Matrix

Applying perspective: 1000px creates a virtual camera located along the positive $Z$-axis. As an element rotates, points closer to the camera are magnified according to the perspective projection formula:

Scale = d / (d - z)

Where $d = 1000\text{px}$ is distance to viewport and $z$ is spatial coordinate.

2. Y-Axis Euler Rotation Matrix

When toggled, the inner chassis executes a spatial rotation about the $Y$-axis:

R_y(θ) = [ cos θ   0   sin θ ; 0   1   0 ; -sin θ   0   cos θ ]

At $\theta = 180^\circ$, normal vector flips, hiding the front face via backface-visibility.

SECTION 07 Linguistics

Kannada Script Rendering & Unicode Handling

Kannada (ಕನ್ನಡ) is a southern Brahmic abugida script. Unlike Latin scripts where each letter represents a standalone glyph, Kannada constructs complex orthographic syllables (ಅಕ್ಷರಗಳು) composed of base consonants, virama (್ - halant), and subscript consonant signs (ಒತ್ತಕ್ಷರ).

OpenType Font Shaping

Without specialized font shaping, browser engines fall back to generic system typefaces that break sub-base conjunct ligatures (e.g. ರ್ಕ or ಷ್ಟ). OmniView injects Google Fonts' Noto Sans Kannada to ensure standard HarfBuzz/DirectWrite rendering.

Regex Grapheme Boundaries

Splitting strings via string.split('') breaks multi-codepoint Kannada graphemes into broken symbols. OmniView's word tokenizer splits explicitly by Unicode whitespace /\s+/, preserving all diacritics.

Issue: Kannada Speech sounds English or is silent

The host operating system lacks a Kannada language speech model. In Windows, install the Kannada (India) Speech Package via Settings > Time & Language > Speech. On macOS/iOS, enable Accessibility > Spoken Content > Voices > Kannada.

Issue: CORS Error (Failed to fetch items.json)

Occurs when double-clicking index.html directly into a browser using the file:/// protocol. Click the Pick File from Disk button in the UI or launch via npx serve or python -m http.server.
